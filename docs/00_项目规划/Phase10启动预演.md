## 2. 范围与禁止项

本阶段实现页面跳转、新窗口、弹窗、外链、跨页参数、联动与清除、声明式下钻、返回和面包屑，并在预览态接线。页面栈、弹窗栈、下钻栈、联动值、弹窗几何和事务状态均为会话状态，不写回 V3 JSON。

禁止：

- 不进入 Phase11，不实现发布快照、发布态执行、权限、RBAC、认证、生产发布或 AI。
- 不新增 EventBus 旁路、独立循环预算或直接写 Parameter Store 的组件特例。
- 不在核心执行器、验证器、迁移器或运行时中硬编码医院、科室、医生。
- 不使用本地 PostgreSQL 凭据，除非具体测试确有需要；凭据不得进入文件、日志、快照或提交。
- 不自动 commit、push、merge，不提交本地状态、构建产物、日志或测试制品。

## 4. 冻结契约

保留 `setParameter`、`refresh`，新增动作白名单：

- `navigatePage`、`pageBack`、`openPageWindow`
- `openDialog`、`closeDialog`
- `applyLinkage`、`clearLinkage`
- `drillDown`、`drillBack`、`clearDrill`
- `openExternalLink`

未知动作、字段、引用和目标必须 fail closed。页面、弹窗、下钻和联动状态均以 `sessionId + epoch` 隔离，实例作用域另有 revision；旧 epoch/revision 响应只能形成受限审计，不得回写。

| 状态域 | 操作 | 关键约束 |
| --- | --- | --- |
| Page | `push / replace / back / clear / cancel` | 根页不可弹出；切页取消旧页面任务 |
| Dialog | `push / replace / close / clear / cancel` | 仅顶层处理焦点、ESC、遮罩；切页/导入/卸载清理 |
| Drill | `push / replace / back / clear / cancel` | 按会话 epoch 与 `pathId` 隔离；页面实例和组件只记录帧来源，跨页同路径可显式续钻；页面栈 checkpoint 隔离导航分支 |
| Linkage | `resolve / commit / refresh / clear / cancel` | 参数单次原子提交；清除也是参数事务 |

参数事务固定顺序：解析 → 校验全部引用和值 → 构造完整变更集 → Parameter Store 单次提交 → 会话迁移 → 定向刷新 → 记录结果。提交前失败零副作用；提交后取消或刷新失败不回滚，必须记录已提交事实。

外链只允许标准 URL 解析成功的 `http:`、`https:`；拒绝 `javascript:`、`data:`、`file:`。内部新窗口只接受现有页面 ID。浏览器端口固定 `noopener,noreferrer` 并断开 `opener`，被拦截时报告失败且不降级。

弹窗几何受 viewport、最小/最大尺寸和筛选器保护矩形共同约束；无合法矩形时保持上一个合法位置。关闭、切页、导入、替换应用、退出预览和卸载必须取消任务、恢复焦点、移除监听器与遮罩。

## 5. 风险与门禁

| 风险 | 等级 | 门禁 |
| --- | --- | --- |
| 会话状态写回 V3、跨会话污染、安全绕过、敏感信息落盘 | P0 | 立即 No-Go |
| Schema/类型/迁移不同步、EventBus 旁路、参数部分提交、虚假回滚、旧响应回写 | P1 | 节点不得关闭 |
| 页面/弹窗/下钻栈错误、外链 fail-open、保护区覆盖 | P1 | 节点不得关闭 |
| 焦点、ESC/遮罩、边界几何、面包屑或清理不完整 | P2 | Phase10 最终不得遗留 |

Phase10 最终要求 P0/P1/P2 均为 0。
