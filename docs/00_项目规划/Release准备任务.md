# Release 准备任务

本任务在正式切换 GitHub、创建首个公开仓库或发布 Release 前执行。目标是形成可启动、可交接、可审计且不泄露私有资产的发布候选版本。

## 交付物

- 根目录 `README.md`。
- `QUICK_START.md`。
- `AI_Development_Handover.md`。
- `开源清单.md`。
- `私有资产清单.md`。
- Windows 一键启动入口 `start-dev.cmd`。

## 执行顺序

1. 冻结当前 V2/V3 阶段状态，确保 README 与代码一致。
2. 运行构建、全部测试和一键启动验证。
3. 审计 Git 状态、忽略规则、日志、密钥、本地数据和备份。
4. 脱敏固定验证库配置、示例 JSON、截图和验收材料。
5. 完成依赖许可证、漏洞与密钥扫描。
6. 选择开源许可证，补充安全和贡献政策。
7. 在干净目录执行 `npm ci`、构建、测试和冷启动。
8. 复核首个提交的完整文件清单。
9. 创建 GitHub 仓库和远程地址，设置分支保护。
10. 由产品、技术、数据和开源负责人共同确认后发布。
