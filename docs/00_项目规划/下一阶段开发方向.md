## Tab 容器组件（本地已实现，门禁已通过）

原页签按钮条已在当前本地分支按以下契约重构，正式远端状态以后续提交、PR 和 CI 结果为准：

1. 每个 Tab 项保存同页目标组件 ID 列表，而不是保存一段独立文本内容。
2. 设计态支持组件库直接拖入、画布组件拖入、跨 Tab 移动和拖回画布；右侧只读成员列表用于检查归属。
3. 预览态仅显示当前 Tab 对应组件，切换值属于会话状态，不写回 V3 JSON。
4. Tab 点击继续通过 Phase9 EventBus，开放 `tab_id`、`tab_label`、`tab_value` 事件字段。
5. 参数传递复用 Phase8 Parameter Store；需要联动时配置“设置参数”和“刷新/应用联动”动作。
6. 页面切换、导入和卸载必须清理 Tab 会话状态；晚到查询结果继续受现有取消与 epoch 约束。
7. 删除组件或复制页面时同步校验并重写 Tab 内部引用，禁止悬空引用。

本轮采用 `componentIds` 单一归属事实源，不引入 `parentRef` 双写；坐标统一相对真实内容区，并通过原子重挂载服务处理拖入、拖出和跨 Tab。冻结依据见 [Tab 容器拖拽冻结方案](../02_V3架构/Tab容器拖拽冻结方案.md)。本地门禁已通过 Node 286/286、真实 Chromium 24/24、生产构建 7012 modules、官方 npm registry 生产依赖审计 0 漏洞和 `git diff --check`；架构与产品独立终审均为 `ACCEPTED`，当前等待用户复检与推送决策。
