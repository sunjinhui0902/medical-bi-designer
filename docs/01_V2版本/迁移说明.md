# 阶段 0：V2 模型与迁移说明

## 已完成范围

- 看板根模型由 `version: 1` 升级为 `version: 2`。
- 组件数据配置由单一 `dimension`、`field` 升级为 `dimensions[]`、`measures[]`。
- 新增筛选、排序、行数限制、指标引用、参数定义及字段语义的类型模型。
- 新增统一查询结果协议和“查询行 → 分类、系列、表格列”的转换层。
- 正式设计器的默认看板、组件创建、Mock 数据集和数据库数据集均使用 V2 配置。
- 本机草稿优先读取 V2 存储；不存在时自动读取并迁移 V1 草稿。
- 导入 V1 或 V2 看板 JSON 时统一规范化为 V2；导出与保存只写 V2。

## 核心配置示例

```json
{
  "version": 2,
  "sourceKind": "server",
  "datasetId": "dataset-uuid",
  "dimensions": [
    { "field": "month_code", "role": "category", "sort": "asc" },
    { "field": "dept_name", "role": "series" }
  ],
  "measures": [
    {
      "field": "amount",
      "aggregation": "sum",
      "unit": "万元",
      "chartType": "bar",
      "axis": "left"
    },
    {
      "field": "visit_count",
      "aggregation": "sum",
      "unit": "人次",
      "chartType": "line",
      "axis": "right"
    }
  ],
  "filters": [],
  "sort": [],
  "limit": 200
}
```

## V1 到 V2 映射

| V1 | V2 | 默认值 |
| --- | --- | --- |
| `dataConfig.dimension` | `dataConfig.dimensions[0].field` | 角色为 `category` |
| `dataConfig.field` | `dataConfig.measures[0].field` | 聚合为 `sum`，坐标轴为 `left` |
| 无 | `dataConfig.filters` | `[]` |
| 无 | `dataConfig.sort` | `[]` |
| 无 | `dataConfig.limit` | `200` |
| 看板 `version: 1` | 看板 `version: 2` | 导入时自动升级 |

迁移不会把数据集 SQL、数据库密码或凭据目标写入组件或看板 JSON。

## 查询结果协议

运行时查询结果统一为：

- `datasetId`：数据集标识。
- `fields[]`：字段名、显示名与规范化数据类型。
- `rows[]`：原始结果行。
- `rowCount`：总行数。
- `durationMs`：可选执行耗时。

组件转换层统一输出：

- `categories[]`：主分类维度。
- `series[]`：一个或多个指标系列，包含图形类型与坐标轴。
- `columns[]`：维度列与指标列。
- `rows[]`：受组件 `limit` 限制的明细行。

## 阶段边界

本阶段只建立模型、迁移与运行时协议。多字段选择器、多个系列的界面配置和图表渲染在阶段 3、阶段 4 实施。
