# Step4 验收记录

## 本阶段范围

- 组件选中后提供 8 个缩放控制点：四角及四边中心。
- 支持从上、下、左、右及四个对角方向调整组件尺寸。
- 支持自定义画布宽度、高度、背景、网格显示及网格大小。
- 支持自定义看板标题内容、字号、颜色、字重、对齐方式及显示状态。
- 支持自定义组件标题内容、字号、颜色、字重、背景及显示状态。
- 内置模拟数据集，并支持组件的数据集、维度和指标绑定。
- 支持将设计保存到浏览器本机存储，刷新后自动恢复。
- 支持导出和导入看板 JSON。
- 支持预览模式，预览时隐藏编辑面板和控制点。

## 建议人工验收项

1. 依次拖动组件四个角和四条边中心的控制点。
2. 修改画布宽高、背景色、网格及标题样式。
3. 切换图表或指标卡的数据集、维度和指标。
4. 点击保存，刷新网页，确认设计自动恢复。
5. 导出看板 JSON，再选择该文件导入，确认设计恢复。
6. 进入预览模式，确认编辑控件和两侧面板隐藏。

> JSON 下载和本地文件选择涉及浏览器文件交互，功能已经实现，建议在人工验收时完成一次导出和导入闭环。
