# Step5 验收记录

## 完成内容

- 新增 PostgreSQL 数据源管理页面。
- 支持配置数据源名称、Host、Port、Database、Username、Password 和 SSL。
- 支持测试数据库连接。
- 数据库密码仅发送到本机 API，并使用 AES-256-GCM 加密保存。
- 浏览器、看板 JSON 和版本库均不保存数据库密码。
- 新增数据集名称、数据源、SQL 和备注配置。
- 支持执行 SQL 预览、识别字段名称及字段类型。
- 支持保存数据集并在页面刷新后恢复。
- 内置医疗 Demo 数据源，用于在没有真实 PostgreSQL 账号时完成全链路验收。
- 设计器右下角增加“数据源与数据集”入口。

## 只读安全策略

- 仅允许以 `SELECT` 或 `WITH` 开头的查询。
- 仅允许单条 SQL。
- 拒绝 `INSERT`、`UPDATE`、`DELETE`、`DROP`、`ALTER`、`CREATE` 等写入或高风险关键字。
- 拒绝 `SELECT INTO`、`pg_sleep` 和 `dblink` 等风险用法。
- 真实 PostgreSQL 查询在 `READ ONLY` 事务中执行。
- 服务端查询超时为 8 秒。
- 单次预览最多返回 200 行。

## 存储说明

当前个人开发验证版采用本机 JSON 直接覆盖写入数据源和数据集配置，以兼容 Windows 文件替换行为。`server/.data/` 已加入 `.gitignore`。正式版建议升级为数据库存储或带备份恢复的原子写入策略。

## 人工验收建议

1. 打开 `/data-sources`。
2. 使用医疗 Demo 数据库点击“测试连接”。
3. 点击“执行预览”，确认返回 6 行收入趋势数据。
4. 修改数据集名称或备注并保存，刷新页面确认恢复。
5. 点击“验证危险 SQL 拦截”，确认写操作被拒绝。
6. 如有测试 PostgreSQL，新增数据源并使用只读账号测试真实连接。
