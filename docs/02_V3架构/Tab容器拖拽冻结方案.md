# Tab 容器拖拽冻结方案

## 结论

当前页签块只完成内容页切换、组件引用渲染和右侧复选框分配，不满足所见即所得容器要求。本轮按 FineReport `tablayout → tabpane → Tab 设计区域 → 子组件` 的核心流程补齐真实拖拽。

风险等级为高风险，结论为 `CONDITIONAL GO`：完成本文件的契约、状态机和验收矩阵后方可编码；完成真实 Chromium 验收前不得作为可用版本推送。

## 冻结范围

### 唯一归属事实源

- `TabItemConfig.componentIds` 继续作为组件归属的唯一持久化事实源。
- 普通组件仍保存在当前页面的 `components[]`，组件 ID、数据绑定、参数绑定、事件和动作目标均不因移动而改变。
- 不新增 `parentRef`，避免与 `componentIds` 双写后产生组件丢失、重复归属或不可见。
- 一个普通组件最多属于一个内容页；Tab 组件不得进入任何 Tab，暂不支持嵌套。

### 坐标语义

- 根组件的 `position` 相对画布。
- Tab 子组件的 `position` 相对目标 Tab 的内容区域，不相对 Tab 外框或标题面板。
- 内容区域边界按真实 DOM 盒模型计算：扣除外层边框/内边距、组件标题、内容区顶部间距、Tab 布局边框和标题面板；上下标题有效尺寸不小于 38px，左右标题有效尺寸不小于 76px。组件还必须受当前内容页 `padding` 约束。
- 根组件拖入、子组件拖出和跨 Tab 移动必须在一次提交中完成归属与坐标转换。

### 拖拽状态机

```text
Idle
→ Dragging
→ HoverCanvas | HoverTabHeader | HoverTabContent
→ Commit | Cancelled | Rejected
```

- 组件库拖到 Tab 内容区域：直接在目标内容页创建，不先创建根组件。
- 根组件拖到 Tab 内容区域：转为目标内容页子组件。
- 子组件拖到画布：转为根组件。
- 子组件拖到其他 Tab：从旧内容页原子转移到目标内容页。
- 悬停其他 Tab 标题 450ms：只切换设计态当前内容页，不修改默认页签，不执行 EventBus。
- `Escape`、释放到设计器外、非法目标、切页、导入或卸载：恢复拖拽前完整位置快照（含 `zIndex`）和归属，并移除窗口级监听器。

### 安全与失败语义

- HTML5 `DataTransfer` 只接受白名单 MIME 中的组件类型，不反序列化组件对象。
- 重挂载先验证组件、Tab、内容页和唯一归属，再同步提交；验证失败时模型零变化。
- 内容区不足以容纳目标组件时 fail closed；新建 Tab 默认高度可容纳默认图表，但用户缩小后的退化容器不会静默裁剪或改写归属。
- 删除包含子组件的内容页时必须明确告知子组件将移回画布，禁止静默丢失。
- 继续复用 Phase8 Parameter Store、Phase9 EventBus、查询取消和 latest-wins，不建立旁路。

## MVP 范围

- 支持组件库→Tab、画布→Tab、Tab→画布、Tab A→Tab B。
- 支持同一 Tab 内移动、缩放和层级保持。
- 提供有效目标高亮、目标名称、空内容页拖入提示和非法嵌套提示。
- 右侧复选框降级为只读成员列表，拖拽成为主操作。
- 暂不支持 Tab 嵌套、组合多选拖入、跨画布移动和发布态能力。
- 设计态 Tab 选择按设计页面隔离；预览态按 `sessionId + pageInstanceId + componentId` 隔离，返回页面实例时恢复原选择，不写入 V3 JSON。

## 验收矩阵

| 场景 | 验收要求 |
|---|---|
| 组件库拖入 | 在鼠标落点创建于指定内容页，画布根层不出现重复组件 |
| 根组件拖入 | 组件 ID、尺寸、数据和事件不变，仅归属与坐标改变 |
| 跨 Tab 移动 | 悬停标题切换后只属于目标内容页 |
| 拖出 Tab | 转为根组件且视觉位置连续，不被裁剪 |
| 取消与非法目标 | 位置和归属完全恢复，Tab 嵌套被拒绝 |
| 坐标 | 上下左右标题面板、内容边距和画布缩放下落点正确 |
| 持久化 | 保存重载、导入导出、页面复制后归属正确且无悬空引用 |
| 运行时 | 设计态切换不执行事件；预览切换只执行一次；参数和联动保持 |
| 门禁 | 定向 Node、真实 Chromium、Node 全量、生产构建和依赖审计通过 |
