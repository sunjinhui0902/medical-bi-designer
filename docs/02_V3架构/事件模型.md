# 事件模型

事件模型采用“事件 → 条件 → 动作 → 值表达式 → 目标”的声明式结构。该模型属于 Phase9—10；Phase7 只在页面和组件结构中保留空数组，不实现事件总线或动作执行器。

## 核心契约

```ts
interface EventBinding {
  id: string
  enabled: boolean
  event: 'click' | 'doubleClick' | 'valueChange' | 'rowClick' | 'pageEnter'
  conditions?: EventCondition[]
  actions: ActionDefinition[]
  debounceMs?: number
}

type ActionDefinition =
  | SetParameterAction
  | RefreshAction
  | NavigateAction
  | DrillAction
  | OpenDialogAction
  | OpenExternalAction
  | ClearInteractionAction
```

值来源使用结构化表达式：

```ts
type ValueExpression =
  | { kind: 'parameter'; parameterId: string }
  | { kind: 'eventField'; path: string }
  | { kind: 'fixed'; value: unknown }
  | { kind: 'expression'; expression: ParameterExpression }
```

不允许在组件渲染代码中拼接业务 `if`，也不允许用任意字符串模板执行动作。

## 分阶段开放

| 阶段 | 开放能力 |
| --- | --- |
| Phase7 | 仅保留空的 `pageEvents[]`，组件事件不执行 |
| Phase9 | 事件总线、条件、设置参数、刷新 |
| Phase10 | 页面跳转、新窗口、弹窗、外链、下钻和清除联动 |
| Phase11 | 编辑、预览、发布共享同一运行时 |

## 循环控制

运行时必须维护 `transactionId`、触发源和传播深度。同一事务内写入相同参数值时不重复传播；只刷新依赖图中受影响的组件；默认最大传播深度为 10；检测到循环时终止当前事务并输出可读错误。

## 导航与下钻

导航目标使用页面 ID，不使用页面名称。下钻路径按字段与参数声明层级，不将“医院、科室、医生”硬编码进核心执行器。页面栈和下钻栈属于会话状态，不写回设计 JSON。
