# 参数体系

参数体系分为“设计态参数定义”和“运行时参数值”。Phase7 只实现参数定义、模板、校验、持久化和管理界面；参数控件、数据集绑定、SQL 参数化和联动属于后续阶段。

## Phase7 参数定义

```ts
interface ParameterDefinitionV3 {
  id: string
  code: string
  name: string
  type: 'string' | 'number' | 'date' | 'dateRange' | 'singleSelect' | 'multiSelect'
  scope: 'application' | 'page'
  pageId?: string
  required: boolean
  defaultValue?: unknown
  source: ParameterValueSource
  validation?: ParameterValidation
  aliases?: string[]
}
```

Phase7 中 `scope` 固定为 `application`。允许的数据来源为：

- `static`：选项直接保存在参数定义中；
- `dictionary`：只保存内置字典编码；
- `system`：通过受控系统上下文产生默认值。

`dataset`、`derived` 和远程字典来源不在 Phase7 实现。

## 系统模板

| 编码 | 名称 | 类型 | Phase7 默认行为 |
| --- | --- | --- | --- |
| `year_code` | 年度 | `singleSelect` | 引用 `builtin.year` |
| `month_code` | 月份 | `singleSelect` | 引用 `builtin.month` |
| `b_date` | 开始日期 | `date` | 系统日期模板 |
| `e_date` | 结束日期 | `date` | 系统日期模板 |
| `code_lv1` | 一级机构 | `singleSelect` | 只创建定义，不加载真实选项 |
| `code_lv2` | 二级机构 | `singleSelect` | 只创建定义，不加载真实选项 |
| `doctor_code` | 医生 | `singleSelect` | 只创建定义，不加载真实选项 |
| `flag` | 标识 | `string` | 只创建定义 |

内置字典至少包括 `builtin.year`、`builtin.month` 和 `builtin.dateShortcut`。

## 校验规则

- `code` 在同一应用内唯一，并只允许约定字符。
- 参数类型必须与默认值类型一致。
- `dateRange` 必须是合法起止值。
- `multiSelect` 默认值必须是数组。
- 静态选项值不得重复。
- 模板实例化后必须产生独立 ID 和独立对象。
- 导入时校验失败不得覆盖当前有效草稿。

## 阶段边界

| 能力 | 阶段 |
| --- | --- |
| 参数定义、模板、字典、校验、参数中心 | Phase7 |
| 参数运行值、控件、数据集参数声明、绑定和安全 SQL | Phase8 |
| 设置参数与刷新事件 | Phase9 |
| 跨页携带、下钻和导航参数 | Phase10 |
| 预览、发布和会话持久化 | Phase11 |

现有数据集中的 `parameters[]` 是“数据集查询参数定义”，V3 根级 `parameters[]` 是“看板应用参数定义”。二者不得复用同一类型或混合存储。
