# V3 数据模型

V3 将当前单画布 `DashboardModelV2` 升级为看板应用 `DashboardApplicationV3`。Phase7 只建立单默认页结构、迁移和兼容层，不开放多页面操作。

## 根模型

```ts
interface DashboardApplicationV3 {
  version: 3
  id: string
  name: string
  description?: string
  defaultPageId: string
  parameters: ParameterDefinitionV3[]
  pages: DashboardPageV3[]
  theme: ThemeConfig
  runtimePolicy: RuntimePolicy
  extensionRefs: ExtensionRefs
  publishConfig?: PublishConfig
  createdAt?: string
  updatedAt?: string
}
```

`extensionRefs` 在 Phase7 只作为不透明引用保存，不接入权限、缓存、语义层或算法服务。`publishConfig` 可以保留为可选结构，但发布能力不属于 Phase7。

## 页面模型

```ts
interface DashboardPageV3 {
  id: string
  name: string
  code: string
  order: number
  type: 'standard' | 'dialog'
  canvas: CanvasConfig
  titleStyle: DashboardTitleStyle
  controls: ParameterControlComponent[]
  components: DashboardComponentV3[]
  pageEvents: EventBinding[]
}
```

Phase7 的限制：

- `pages[]` 必须且至少包含一个默认页；
- `defaultPageId` 必须指向存在的页面；
- 设计器只读写默认活动页；
- `controls[]`、`pageEvents[]` 固定为空数组；
- 不提供页面新增、复制、删除、排序或切换。

## V2 到 V3 的变化

| V2 | V3 | Phase7 迁移规则 |
| --- | --- | --- |
| 根级 `canvas` | `pages[0].canvas` | 原样迁移，缺失时使用 `1200 × 600` |
| 根级 `titleStyle` | `pages[0].titleStyle` | 原样迁移 |
| 根级 `components[]` | `pages[0].components[]` | 保留 ID、顺序、图层和配置 |
| 无根 ID | 根 `id` | 使用稳定规则生成 |
| 无页面 | `pages[]`、`defaultPageId` | 生成稳定默认页 |
| 无应用参数 | `parameters[]` | 初始化为空数组 |
| 无主题与运行策略 | `theme`、`runtimePolicy` | 写入兼容默认值 |
| 无扩展引用 | `extensionRefs` | 初始化为空对象 |

## 设计态与运行态边界

V3 JSON 保存页面、组件、参数定义、主题与运行策略，不保存本次浏览产生的参数值、页面栈、下钻栈、查询缓存或事务状态。运行时状态不得回写设计 JSON。

## 迁移不变量

- 迁移函数不得修改输入对象。
- 同一输入重复迁移必须产生相同 ID 和相同语义结果。
- V3 输入重复读取不得再次包裹页面。
- 未识别但安全的扩展字段应保留或进入迁移报告。
- 凭据、密码和密钥不得进入 V3 JSON 或迁移报告。
