# 设计器通用能力增强记录

本文记录 2026-08-26 面向公开仓库整理的设计器能力增强。公开版本只包含可复用的产品能力、脱敏测试和通用文档，不包含业务看板、真实数据库连接配置、内部 SQL、机构数据或环境变量约定。

## 完成范围

本轮增强覆盖以下通用能力：

- 多看板本机工作区，支持新建、切换、重命名、复制和删除独立看板。
- 多页面与页签容器管理，支持组件拖入、跨页签移动和拖回画布。
- 预览画布的实际大小、适应宽度和适应窗口三种模式。
- 普通组件 20 × 20 的产品级最小尺寸，以及横向、纵向装饰线条特例。
- 文本、图片、图标、形状、表格和地图等受控内容组件。
- 表格分页、固定表头、条件格式、状态徽标和主题化样式。
- 数据集驱动的动态选项、参数依赖、级联筛选和失效值清理。
- 受控的组件联动、参数传递、下钻、页面导航、返回和弹窗动作。
- 地图底图、GeoJSON 面层和经纬度点图层的通用渲染能力。
- 深色主题下的图表、指标卡、表格和预览视觉适配。

## 公开仓库边界

以下内容明确不进入公开仓库：

- 具体客户、机构或监管业务看板。
- 真实数据库地址、端口、库名、用户名和连接别名。
- 数据库密码、凭据目标、访问令牌和私有证书。
- 真实 schema、表名、字段映射、指标编码和业务 SQL。
- 真实医疗、运营、财务、风险和机构明细数据。
- 依赖外部私有数据库才能通过的自动化测试。

公开测试使用模型对象、合成数据或本机 Demo 数据验证产品契约。真实数据集验收应在私有环境独立执行，不应成为公开 CI 的前置条件。

## 验收要求

公开分支合并前必须满足：

1. 全量单元测试通过。
2. 完整 Chromium E2E 通过，且不依赖私有数据库或凭据。
3. TypeScript 检查和生产构建通过。
4. 高危依赖审计通过。
5. `git diff --check` 通过。
6. 仓库扫描不出现业务连接信息、内部表结构、真实 SQL 或敏感数据。
