# 交互与画布自定义补充需求

Step3 已由用户人工验收通过。以下内容为后续版本的强制需求，其中八方向缩放作为 Step3.1 补强项优先实现；画布和标题自定义与 Step4 的 JSON 持久化一起实现，确保配置可以保存、导出和恢复。

## 八方向缩放

组件被选中后，需要同时显示八个缩放手柄：左上、上中、右上、右中、右下、下中、左下、左中。每个手柄使用对应方向的鼠标指针，并支持连续拖动。

缩放行为必须满足：

- 拖动右侧或下侧手柄时，仅修改宽度或高度。
- 拖动左侧或上侧手柄时，同时修改组件位置和尺寸，组件另一侧保持固定。
- 拖动四个角时，同时修改水平和垂直方向。
- 组件不能突破画布边界，也不能小于组件定义的最小尺寸。
- 右侧布局面板的 X、Y、W、H 必须随拖动实时更新；通过输入框修改数值时，手柄和组件位置也必须同步。
- ECharts、表格和文本内容必须随容器尺寸重新布局，不能溢出或失真。

## 画布自定义

后续支持在“页面 / 画布设置”中调整画布宽度和高度，并提供常用尺寸预设与自定义输入。画布背景色、网格显示和网格间距也纳入同一配置模型。

画布配置必须保存到看板 JSON，而不是只存在于 CSS；导出后重新导入应恢复相同尺寸和背景。

## 标题自定义

标题配置分为两个层级：

- 看板标题支持修改文字、字号、颜色、粗细、对齐方式和显示状态。
- 组件标题支持修改文字、字号、颜色、粗细和显示状态；现有“样式”Tab 继续作为配置入口。

标题设置必须即时反映到画布，并进入对应的 `styleConfig`。后续 JSON 导入、模板复制和版本管理都应复用这一结构。

## 验收标准

- 选中任意组件时可以看到并操作八个缩放手柄。
- 八个方向的缩放结果均与右侧布局坐标一致，且受最小尺寸和画布边界限制。
- 自定义画布尺寸后，设计区域和 JSON 配置同步变化。
- 修改看板标题或组件标题的字号、颜色和对齐方式后，画布即时更新。
- 保存、刷新或导入 JSON 后，画布与标题配置能够完整恢复。
