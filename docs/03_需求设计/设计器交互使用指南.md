# 设计器交互使用指南

本文说明如何在设计态配置组件交互，并在预览态验证。设计态只保存配置，只有进入“预览”后才执行页面跳转、弹窗、联动和下钻。

## 快速开始

1. 在画布中选中需要响应操作的组件。
2. 打开右侧“交互”页签，点击“配置组件事件”。
3. 在“新建事件”中选择单击、双击、值变化或行单击。
4. 按需要添加条件；没有条件时，事件每次都会执行。
5. 添加一个或多个动作，点击“应用”。
6. 回到设计器点击“预览”，实际操作组件验证结果。

## 常用事件

| 事件 | 适用场景 |
| --- | --- |
| 单击 | 指标卡、图表点位、页签等普通点击操作 |
| 双击 | 需要避免误触的详情跳转 |
| 值变化 | 参数控件或值型组件变化 |
| 行单击 | 表格点击某一行并携带该行字段 |
| 页面进入 | 页面首次进入时自动刷新或初始化 |

## 常用动作

- “页面跳转”在当前窗口打开目标画布，可选择压入历史或替换当前页。
- “返回上一页”回到页面栈上一层。
- “新窗口打开页面”在新窗口打开内部画布，并可携带指定参数。
- “打开弹窗”打开弹窗型页面；弹窗支持拖动、缩放、ESC 和遮罩关闭策略。
- “设置参数”把固定值、当前参数或事件字段写入 Parameter Store。
- “应用联动”和“清除联动”控制指定组件的定向刷新。
- “下钻”“返回上级”和“清除下钻”使用已声明的 DrillPath。
- “打开外部链接”仅允许安全协议，危险协议会拒绝执行。

## 示例：点击科室跳转医生页

在科室表格上新建“行单击”事件，先添加“设置参数”动作，把行字段中的科室编码赋给应用参数；再添加“页面跳转”动作，目标选择医生页面。应用后进入预览，点击一行即可携带科室参数跳转。

## 示例：页签切换后联动组件

页签组件会提供“页签 ID”“页签名称”“页签值”三个事件字段。可以在页签“单击”事件中把“页签值”写入参数，再添加“应用联动”或“刷新”动作。页签中的普通组件仍使用自己的点击、双击或行单击事件，参数传递方式与画布普通组件一致。

页签内容的添加、标题面板和组件绑定详见 [设计器看板与页签使用指南](./设计器看板与页签使用指南.md)。

## 排查顺序

交互未执行时，依次确认：事件已启用、草稿已点击“应用”、当前处于预览态、条件能够成立、目标页面或组件仍然存在、事件字段路径与组件实际绑定字段一致。
