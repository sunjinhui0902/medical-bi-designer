# 设计器参数使用指南

参数分为“参数定义”“画布筛选控件”“数据集参数绑定”三层。先创建定义，再把参数放到画布，最后把它绑定到需要刷新的真实数据集组件。

## 创建参数

1. 从设计器左侧“数据管理”进入“参数中心”。
2. 新建参数，填写名称、编码、类型、作用域和是否必填。
3. 单选、多选参数应配置静态选项、内置字典或数据集选项来源。
4. 保存后返回设计器。

参数编码建议使用稳定英文编码，例如 `year_code`、`dept_code`。同一业务含义不要创建多个不同编码。

## 添加到画布

在左侧“参数筛选器”中找到参数，点击“添加”。系统会按参数类型自动生成文本框、单选、多选、日期或日期范围控件。已添加的参数会显示“已添加”，并出现在当前画布顶部。

当前版本暂不显示单个参数控件的“清空”按钮，以避免在筛选区出现密集的大号清空入口。底层清除协议和已有 V3 `clearable` 配置继续保留，后续会以统一筛选操作区替换；如需改值，直接重新选择或输入并提交。

## 绑定真实数据集

1. 选中需要查询真实数据的组件。
2. 点击“为当前组件选择数据集”，单击目标数据集后再点击“确认切换”。
3. 在右侧“字段”页签检查维度、指标和刷新策略。
4. 在“数据集参数绑定”中，把数据集参数映射到同类型的应用参数。
5. 必填数据集参数必须绑定，或由数据集提供默认值。

参数值提交后，仅刷新声明依赖该参数、且刷新策略为“参数变化时刷新”的组件。

## 参数与交互联动

组件事件可以使用“设置参数”动作写入参数，再通过“刷新”“页面跳转”“应用联动”继续处理。跨页携带参数和弹窗参数均由同一 Parameter Store 原子提交，失败时不会写入一半。

## 常见问题

- 画布中找不到参数：确认参数已在参数中心保存，并刷新设计器。
- 数据集参数下拉没有候选项：检查参数类型是否兼容、编码或别名是否匹配。
- 修改参数后组件不刷新：检查组件是否绑定该参数，以及刷新策略是否为“参数变化时刷新”。
- 必填参数报错：先在画布控件中选择值，再触发查询或交互。
