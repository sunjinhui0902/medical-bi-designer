# 固定验证数据库示例

公开仓库只提供脱敏配置示例。真实验证数据库地址、账号、数据源 ID 和密码必须保存在本机私有配置中。

| 配置 | 示例值 |
| --- | --- |
| 数据源名称 | `local-postgres` |
| DataSource ID | `source-example` |
| Host | `127.0.0.1` |
| Port | `5432` |
| Database | `medical_bi` |
| Username | `readonly_user` |
| Default Schema | `public` |
| SSL Mode | `prefer` |

复制 `server/validation-database.example.json` 为 `server/validation-database.json` 后填写本地真实值。实际配置文件已被 `.gitignore` 排除。

密码不得写入该 JSON、前端代码、看板 JSON、文档或版本库。应通过本机私有存储或环境变量提供。
