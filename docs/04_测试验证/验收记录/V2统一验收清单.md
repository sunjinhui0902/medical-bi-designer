# 医疗 BI Designer 阶段 0—5 统一验收清单

本清单用于统一验证 V2 模型、固定数据库、数据集 2.0、多字段绑定、常用图形和分析配置。建议按顺序执行；发现问题时记录“编号、操作、预期、实际结果和截图”。

## 启动与固定验证库

- [ ] A01 在 `E:\codex\个人开发版` 执行 `npm run dev`，网页 `http://127.0.0.1:5173/` 能打开。
- [ ] A02 打开 `/data-sources`，默认选中 `odr`，并显示“固定验证库”。
- [ ] A03 使用本机私有验证配置中的 Database、只读 Username 和 Schema。
- [ ] A04 点击“测试连接”，提示连接成功。

## 数据集 2.0 打通

- [ ] B01 在 `/data-sources` 左侧点击任意已保存数据集。
- [ ] B02 页面跳转到 `/datasets?id=数据集ID`，不是进入空白的新建状态。
- [ ] B03 2.0 页面打开的数据集名称、SQL、数据源和字段与所点击的数据集一致。
- [ ] B04 在 2.0 左侧切换其他数据集，右侧立即打开对应配置，地址栏 ID 同步变化。
- [ ] B05 点击右上角新增按钮后才进入新建状态，默认数据源为 `odr`。

## 数据集目录与元数据

- [ ] C01 搜索名称、编码或字段，可以缩小数据集结果。
- [ ] C02 状态筛选支持草稿、已验证和已停用。
- [ ] C03 分类筛选和分页可用。
- [ ] C04 名称、编码、分类、用途和说明保存后，重新打开仍然存在。
- [ ] C05 点击“复制”生成草稿副本，原数据集不被覆盖。
- [ ] C06 状态管理可以切换草稿、已验证和停用。

## SQL、字段语义与参数

- [ ] D01 输入只读 `SELECT` 或 `WITH` SQL，点击“执行测试”返回预览结果和耗时。
- [ ] D02 非只读 SQL 被拦截。
- [ ] D03 执行成功后自动解析字段名和类型。
- [ ] D04 字段可以配置中文名、维度/指标/参数/辅助角色。
- [ ] D05 指标字段可以配置 SUM、AVG、COUNT、MIN、MAX、单位和数字格式。
- [ ] D06 点击“关联”后显示已关联；再次点击可解除关联。
- [ ] D07 可添加文本、数字、日期、日期范围、单选和多选参数。
- [ ] D08 保存并重新打开后，字段语义、指标关联和参数保持不变。

## 看板 V2 与多字段绑定

- [ ] E01 打开设计器并选择组件，在“数据”页能看到维度和指标两个字段槽位区域。
- [ ] E02 维度支持添加多个字段，并可选择分类、系列或明细角色。
- [ ] E03 指标支持添加多个字段，并可设置聚合、柱/线/面积、左轴/右轴及系列名称。
- [ ] E04 维度和指标支持上移、下移及删除。
- [ ] E05 保存看板并刷新页面，多字段顺序和配置能够恢复。
- [ ] E06 “看板 JSON”中使用 `dimensions[]`、`measures[]`、`filters[]`、`sort[]` 和 `limit`，没有回退到单一 `dimension/field`。

## 常用图形与表格

- [ ] F01 柱状图绑定 1 个维度和多个指标后，显示多个系列。
- [ ] F02 折线图绑定 1 个维度和多个指标后，显示多条折线和图例。
- [ ] F03 面积图能够显示面积系列。
- [ ] F04 组合图的不同指标可分别选择柱、线或面积。
- [ ] F05 组合图的指标可分别放置在左轴和右轴。
- [ ] F06 饼图使用第一个维度和第一个指标正常显示。
- [ ] F07 散点图使用前两个指标作为 X/Y 值。
- [ ] F08 气泡图使用前三个指标作为 X/Y/气泡大小。
- [ ] F09 表格支持多个维度和多个指标，并按字段槽位顺序显示列头和数据。
- [ ] F10 字段不足时页面不崩溃，空系列或空表格可正常显示。

## 图表分析配置

- [ ] G01 在图表组件“样式”页能配置左轴和右轴最小值、最大值。
- [ ] G02 开启数据标签后，图表显示数值标签。
- [ ] G03 标签小数位和位置调整能够立即生效。
- [ ] G04 添加预警线后，可以设置阈值、名称和颜色。
- [ ] G05 删除预警线后图表同步移除。
- [ ] G06 分析配置保存并刷新后能够恢复。

## 布局与兼容性回归

- [ ] H01 组件选中后，四角和四边中心共 8 个缩放手柄均可使用。
- [ ] H02 画布宽高、看板标题字号和组件标题字号仍可自定义。
- [ ] H03 旧草稿可以打开，组件自动拥有 V2 数据配置和分析配置。
- [ ] H04 Mock 数据组件和 `odr` 真实数据组件均能正常使用。
- [ ] H05 设计态和预览态没有白屏、错位或明显控制台错误。
