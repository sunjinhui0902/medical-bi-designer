# 医疗BI Designer V2之后 AI能力与智能分析方向规划

版本：V1.0

定位：

本文作为医疗BI Designer V2完成后的长期方向指导文档。

目标：

在BI Designer底座、数据集体系、指标体系完善后，引入：

-   AI大模型能力
-   AI自动生成看板

-   数据挖掘算法

医疗数据中台 + BI设计器 + AI分析助手 的智能运营分析平台。

# 五、AI生成看板技术设计

## 不让AI直接写代码

错误方式：

    用户

    ↓

    AI

    ↓

    HTML代码

问题：

-   不稳定
-   难维护
-   无数据绑定

------------------------------------------------------------------------

## 正确方式

    用户需求

    ↓

    AI模型

    ↓

    BI标准JSON

    ↓

    Designer渲染

    ↓

    真实数据展示

------------------------------------------------------------------------

## AI输出标准

固定JSON Schema。

例如：

``` json
{
"dashboard":"门诊运营分析",

"components":[

{
"type":"chart",

"chartType":"line",

"indicator":"门诊人次",

"dataset":"op_visit_month"

}

]

}
```

# 八、第三阶段：AI数据分析助手

## 目标

从：

查询数据

升级为：

解释数据。

------------------------------------------------------------------------

## 示例

用户：

    分析7月份收入下降原因

AI流程：

第一步：

发现异常：

收入下降10%

第二步：

拆分：

科室维度

发现：

外科下降18%

第三步：

继续分析：

手术量下降

第四步：

输出原因。

------------------------------------------------------------------------

输出：

    7月份收入下降主要原因：

    1.

    外科收入下降18%

    影响金额：

    120万元


    2.

    手术量下降15%


    3.

    某重点科室门诊量下降


    建议：

    关注外科排班及手术资源使用情况

------------------------------------------------------------------------

# 九、数据挖掘算法能力规划

## 1. 异常检测（优先实现）

价值：

最高。

实现难度：

较低。

------------------------------------------------------------------------

应用：

收入异常

工作量异常

患者量异常

成本异常

------------------------------------------------------------------------

算法：

### Z-Score

判断：

数据是否偏离正常范围。

------------------------------------------------------------------------

### IQR

判断：

异常点。

------------------------------------------------------------------------

### 移动平均

判断：

趋势偏离。

------------------------------------------------------------------------

结果：

生成：

异常事件。

------------------------------------------------------------------------

示例：

    异常：

    骨科收入下降

    下降：

    22%

    超过历史波动范围

    风险等级：

    高

------------------------------------------------------------------------
