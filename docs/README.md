# Medical BI Designer 文档中心

本目录按“项目规划、V2 基线、V3 架构、需求设计、测试验证、AI 规划”分类。当前入口是 [项目当前状态](./项目当前状态.md) 与 [总体架构规划和开发合并方案](./02_V3架构/总体架构规划与开发合并方案.md)；最新阶段证据见 [Phase10 验收记录](./02_V3架构/Phase10验收记录.md) 与 [Phase10 最终验收](./02_V3架构/Phase10最终验收.md)。

正式创建 GitHub Release 或进入生产发布前，仍须复核 [Release 准备任务](./00_项目规划/Release准备任务.md) 与根目录的开源、私有资产清单。
