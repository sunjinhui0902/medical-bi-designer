## 根因与调整

GitHub 的干净环境初始化为空数据集目录。旧测试依赖真实目录自动选择首项，从而发出详情请求；没有数据时，等待详情的 Promise 永远不完成，30 秒超时。Windows 本地已有目录，因此此前本地完整 E2E 能通过。

测试改为通过浏览器路由拦截提供独立合成目录、空数据源列表与延迟详情。分别覆盖目录自动选择和空目录使用 URL 指定数据集，两条路径都在详情挂起时切换到数据源页，再释放响应，确认仍停留在数据源页。关键等待使用有界断言，失败清理保证释放挂起请求。

应用实现、业务数据及数据库连接配置未改变。测试不执行 SQL、不写数据库，不依赖本地医院数据。阶段预演结论 go；回滚只需恢复该测试与说明文档。
