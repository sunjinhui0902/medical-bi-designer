## 冻结方案

在现有原生组件上增加可选 groupId 与 styleConfig.pointerEvents，旧配置默认保留现有行为。组合只包含同一页面、同一画布或同一 Tab 内容页的普通组件；不组合 Tab 容器，不建立嵌套组合。跨 Tab 移动先取消组合。

通过可见图层与组合面板提供成员选择、组合/取消、图层排序、透明背景、装饰层点击穿透及组整体位置与尺寸；通用拖拽作用于组合全部成员，越界限制、最小尺寸和 Escape 取消保护全部成员。删除成员后清理退化组合。

移动布局按组合外包络重排，组内坐标与视觉整体同比缩放，桌面坐标及业务绑定不变；同样覆盖 Tab 内容页。仅在预览启用点击穿透，设计态仍可通过图层列表选中和编辑装饰组件。

配置结构和语义校验、组合变换/边界/取消测试、旧配置回归、真实页面组合与叠放/下层点击/Tab/手机/保存重开和构建作为验收。不得用视觉测试 Mock 指标替代门诊业务结论。

## 已实现与使用方式

在 PC 设计器工具栏打开“图层 / 组合”。选中同一画布或同一 Tab 内容页内的组件，勾选成员后组合；通过紫色组合边框整体拖动、八方向缩放，或在面板填写 X/Y/宽/高。Escape 恢复全部成员。面板提供置顶、上移、下移、置底、透明背景、预览点击穿透和取消组合。

原生配置保存 groupId、pointerEvents 和各成员位置，不改变指标绑定与交互配置。单组件模板插入时清理组合标识；删除后清理不足两个成员的组合。跨容器移动须先取消组合；不支持 Tab 容器成组、嵌套组或手机编辑。
