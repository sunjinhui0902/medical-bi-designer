## 当前能力

| 需求 | 当前状态 | 使用边界 |
| --- | --- | --- |
| 多种组件放进同一 Tab 内容页 | 支持 | 支持拖入、跨页签移动、拖回画布、标题四方向、默认项与隐藏项、保存重开；禁止 Tab 容器嵌套 |
| 任意组件成组 | 尚未实现 | 批量平移保持所选组件相对位置，当前没有持久化组合、取消组合、组整体缩放或组模板 |
| 图片、指标卡、图表等叠放 | 配置及桌面渲染支持 | 使用位置、zIndex、背景与边框；图片放下层，指标卡放上层，保存重开保留叠放。属性面板缺少显式层级和统一透明背景入口 |
| 点击穿过透明装饰组件 | 当前缺少配置入口 | 上层组件即使背景透明仍接收点击，可能遮挡下层图表、筛选或下钻 |
| 手机保留叠放组合 | 当前未支持 | 自适应按独立组件重排成单列，叠放关系会被拆开；Tab 子组件也按单列重排 |

Tab 切换可在预览执行配置事件，提供 tab_id、tab_label、tab_value 参数。基础 Tab 操作已验证；本轮没有覆盖大量页签、长标题、复杂图表首次显示和所有移动浏览器。

## 建议顺序

1. 图层置顶/置底/上移/下移、明确透明背景与装饰层点击穿透，改善叠放的可编辑性。
2. 组合/取消组合及整体移动与缩放，保存成员和相对位置。
3. 移动端按组合重排，保持组内叠放；Tab 组件同步覆盖此策略。

以上为能力复核建议，尚未实施新功能。产品继续采用 PC 设计、手机预览与自适应浏览的范围。
