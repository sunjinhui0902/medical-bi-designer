# 看板菜单与配置式联动演示

医院概览的独立工具栏按钮和自动加载地址已移除。入口统一在“当前看板 → 看板管理”，已创建的医院概览直接选列表项；菜单“示例看板”首次创建医院概览或科室业务演示并自动保存，再次点击会打开已有示例，保留原看板。

演示名称：科室→医生 · 本地业务演示。三个画布：科室练习、科室医生、医生详情。数据来自已有 bd_odr 科室/医生只读聚合快照；8 个科室的部分医生样本，不代表全院合计。未选科室时医生表展示 20 行，选科室后展示该科室的 10 行。

## 查看与修改配置

退出预览，选中表格 → 右侧“交互” → “编辑交互规则”。单条已有联动规则打开时自动选中，直接显示当前触发、目标组件、目标参数与传递字段；科室样本的字段显示“科室编码”等业务标签。多动作下钻和跳转自动进入“高级编辑”，可检查完整动作顺序。修改后点“应用”，关闭配置，再保存看板、进入预览。

| 对象 | 触发方式 | 原生配置 |
|---|---|---|
| ① 点击科室联动右表 | 点击表格行 | 应用联动：行字段 dept_id → 科室参数；目标为科室医生样本表 |
| ① 科室医生样本 | 参数变化 | 数据绑定：month → 样本月份，dept_id → 科室；参数变化刷新 |
| ② 点击科室下钻 | 点击表格行 | 清除联动 → 下钻“科室→医生” → 页面跳转“科室医生” |
| 科室医生 · 点击行继续下钻 | 点击表格行 | 下钻“科室→医生” → 页面跳转“医生详情” |
| 当前医生门诊人次 | 参数变化 | 数据绑定：month、dept_id、doctor_id 分别对应月份、科室、医生参数 |
| 一键重新开始 | 点击 | 清除联动 → 清除下钻 → 页面跳转“科室练习” |

所有动作均保存在标准 V3 看板的 events、parameters、parameterBindings、drillPaths 和 pageEvents 中。本次未修改底层交互运行时，也没有专用点击回调。样例生成器仅装配原生配置。
