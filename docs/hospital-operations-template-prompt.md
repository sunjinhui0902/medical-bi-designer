# 医院运营概览模板提示词

将下方提示词与参考截图、知识库指标目录及本地指标 JSON 一起提供给 AI。截图只提供布局，不提供实绩数据。下方是最初独立HTML样例的提示词；医院概览现已增加ChatGPT网页协作与API模型入口，真实网页方案进入原生设计器的验收见[设计器验收](./hospital-model-designer-20260929.md)。连续AI修改仍未接通。

## 可直接复制

你是一名医疗 BI 看板设计师。请以附件“医院运营概览”截图为视觉模板，结合所提供的知识库指标定义、字段绑定和本地数据 JSON，生成一个可独立打开的医院运营概览 HTML 样例。

1. 保持截图的蓝白风格：浅灰蓝背景、白色圆角卡片、亮蓝主色、紧凑但清晰的字体。桌面布局左侧约 39%、右侧约 61%。顶部标题、导航和年月筛选；左侧 2×2 KPI 与收入到利润结构；右侧 7 个小指标、收入趋势、科室红绿灯、收入结构双环图、床位使用散点区域。小屏改为顺序堆叠，不能遮挡文字。
2. 先按知识库建立“模板位置→指标 ID→字段→单位→粒度→来源”的映射。不得将门诊收入冒充总收入或医疗收入，不得将医疗成本冒充总成本；无法匹配的原位置保留为空。可以在空位置附加明确命名的已有指标，例如“医疗成本（本地已绑定）”。
3. 仅使用输入 JSON 中的真实非 null 数值。金额原始单位元，展示万元时除以 10000；比例原始值为比值时乘 100 展示百分比；人次不换算。同比、环比优先使用同一指标历史月份，比较基数为 0 或历史缺失时显示“—”。金额保留两位小数，人数使用千分位。
4. 预算、预算达成、总收入、总成本、结余率、收入构成、科室收入及科室床位散点没有数据时保持 null，显示“暂无数据”和具体缺口。不得补零、复制截图数字、生成随机点、凑占比、填无限大或编造科室排名。没有明细的数据，不生成可点击的假下钻。
5. 默认展示 2026 年 08 月当月数据，趋势展示本年 01 月至所选月份。年月筛选须真实联动全部已有数据；支持同比/环比切换，点击趋势柱切换月份。每张已有指标卡点击后展示指标名称、单位、来源、快照日期、口径限制。筛选值必须来自有效月份。
6. 保留“本地样例 / 知识定义暂定 / 已验证只读快照”说明。缺口不阻止整个看板生成，后续可补绑定再生成。只显示本地测试证据，不暗示实时经营数据。
7. 输出完整 HTML、本次指标映射、数据缺口清单和验证结果。不要依赖远程 CDN；图表库随文件内嵌。完成后验证年月联动、单位、比较、空值、图表渲染、来源提示和窄屏布局，并提供截图。

## 生成命令

在项目目录执行 `npm run demo:hospital`，或 `node scripts/generate-hospital-operations-demo.mjs --year 2026 --month 08`，得到 `public/hospital-overview-sample.html`。也可通过 `--out <路径>` 输出到其他位置。生成器仅读取已验证证据，不执行数据库查询。生成后可从“知识库 → 本地看板助手 → 查看医院运营概览模板样例与提示词”打开。

## 本轮映射

| 模板位置 | 当前绑定 | 处理 |
| --- | --- | --- |
| 总收入、医疗收入、总成本、结余率 | 未绑定 | 原位置为空；总成本卡附加“医疗成本”独立指标 |
| 门诊收入、门急诊人次、出院人次、病床使用率 | 对应 dashboard_* 指标 | 当月真实快照 |
| 次均费用、住院收入 | 未绑定 | 空值，不擅自计算 |
| 收入趋势 | dashboard_outpatient_revenue | 明确标注门诊收入趋势 |
| 瀑布、双环、科室收入、床位散点 | 未绑定明细 | 保留区域及缺口说明 |
| 预算及达成率 | 未绑定 | 空值 |

已有本地指标默认按知识库暂定口径展示，异常后再调整；截图中的数字完全不参与样例计算。
