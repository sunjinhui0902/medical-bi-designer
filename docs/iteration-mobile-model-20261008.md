## 冻结边界

产品范围按最新需求确认：在 PC 设计看板，支持手机/平板预览及移动端自适应浏览。

移动端仅改变运行时展示位置，不写回桌面组件坐标；手机/平板预览为会话选项，自适应开关存入 V3 `extensionRefs.responsiveLayout`，随看板保存和导出。按桌面 y/x 顺序重排为单列；保留原数据、参数、事件与下钻。页签容器内也重排，装饰类仍保留。旧看板默认关闭，可显式开启。

批量平移使用既有展示预览/应用/撤销契约，选择当前页顶层组件，校验整体边界；容器与成员一同移动时不重复移动成员。不扩大为框选、任意嵌套群组或核心拖拽重构。

跨模型使用可复制提示词、小型 JSON 计划和本地编译器；不要求模型编写复杂 V3 ID/SQL/脚本。输出校验失败不静默使用模板假装模型成功。千问 32B 的具体版本、量化、推理服务及配置待确认；以同一提示词和验收集对比，不能从参数量预判效果。
