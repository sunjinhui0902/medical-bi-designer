## 模型 API

打开 http://127.0.0.1:5174/model-settings 。选择模型服务，填写实际 API 地址、模型名和 API Key，依次点击“保存配置 → 测试连接 → 设为默认”。模型名称以服务账号支持的名称为准。密钥由页面提交到本机服务端，不在聊天中提供。

配置成功后进入“知识库与看板助手”，使用门诊目标和提示词样例验证模型生成，再导入设计器、保存重开。当前任务未代填 Key、未调用收费模型，也未验收具体模型的生成效果。

## 电脑手机预览步骤

1. 返回设计器，点击顶部“当前看板”旁的看板名称，打开看板管理。
2. 选择已保存的门诊看板；也可选择“门诊运营分析 · 五页样例”打开本地样例。
3. 勾选画布上方的“移动端自适应”，保存一次。
4. 点击顶部“预览”，将画布上方“设备”切换为“手机 · 390”。“平板 · 768”可用于平板检查。
5. 切换月份，点击科室排名进入科室页；再选择科室、点击医生或下钻入口进入医生页。逐级点击“返回”，确认筛选状态和页面内容。
6. 切换 Tab 页签、滚动到页面底部，检查标题换行、单位、表格滚动，以及图片和指标卡组合是否裁切。
7. 点击表格中的“下载明细 CSV（已加载 N 行）”，检查 CSV 的实际数据行和筛选月份。该按钮下载已加载的明细，顶部“导出”下载看板 JSON。
8. 退出预览，保存并刷新页面，确认自适应开关和布局保留。

需要验证 320px、横屏或浏览器视口自适应时，在 Edge/Chrome 打开页面，按 F12，再按 Ctrl+Shift+M 切换设备模式。预览中的“设备”选择“桌面 / 自动”，将设备宽度设为 320、390、768 或 1024。固定“手机 · 390”主要检查指定画布宽度，浏览器设备模式检查整个页面在窄屏中的展示。

这些方式属于电脑模拟，不代表已通过 iOS Safari、Android 浏览器或微信内置浏览器真机验收。当前 BI 服务仅监听本机，手机不能直接打开电脑的 127.0.0.1 地址。
