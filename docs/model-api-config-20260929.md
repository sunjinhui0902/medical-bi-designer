# 模型 API 配置入口

本轮增加本地模型配置页 `/model-settings`。设计器与知识库导航均有“模型配置”入口。

当前主线已包含保存列表与调用选择，随 PR #15 合并。下面的使用步骤为最新入口；原始验收章节保留 2026-09-29 的时间点结果。

## 使用

1. 选择 Gemini、DeepSeek、通义千问（阿里云百炼）或其他 OpenAI 兼容服务。
2. 填写 API Key；服务地址与模型名称可按账号支持情况修改。
3. 点击“保存配置”，在“已保存模型”列表确认服务、模型名称和默认状态；不同服务分别保留。
4. 点击“测试连接”。需要改变默认入口时点击“设为默认”。连接成功只证明所测请求可用，不等同于完整业务生成效果通过。
5. 返回设计器，打开“本地看板助手”，填写需求，在“本次调用模型”选择已保存服务及月份，点击“使用所选模型生成医院概览”。本次选择不改默认模型。生成的是受控模板计划，经项目校验后进入原生设计器，可编辑、保存、重开。
6. 门诊可用“提示词样例”复制业务提示词给其他模型，再粘贴七字段 JSON 计划进行校验和 V3 编译；示例填入不代表模型实际生成。详见 [跨模型提示词](./outpatient-portable-prompts-20261008.md)。

例如：`按医院运营概览模板生成2026年8月看板，包含核心指标、医疗收入趋势、科室收入、收入结构和床位使用情况。使用知识库口径及本地ADS快照，预算缺失保持空值。`

“使用 ChatGPT 网页”保留现有 Codex 协作入口。API 调用使用“本次调用模型”所选服务，网页生成请求仍可单独使用。

API Key 在本机服务端复用 AES-256-GCM 加密保存，不保存在浏览器存储；配置接口仅返回“是否已保存”。修改地址或模型时留空保留密钥，勾选“清除”并保存才删除。连接测试会调用所选模型并可能产生费用；保存不会调用模型。
