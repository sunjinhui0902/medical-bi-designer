## 功能与入口

| 功能 | 操作方式 |
| --- | --- |
| 深浅主题 | 设计器画布工具条选择“深色驾驶舱”或“浅色日常分析”，保存后可重开 |
| 对齐参考线 | 勾选“对齐参考线”，拖动时显示边缘和中心线并吸附；按 Alt 暂停吸附 |
| 批量布局与组合 | 在批量布局、图层组合面板勾选组件，检查画布高亮后调整位置；组合可整体拖动、缩放，也可取消组合 |
| 配置窗口 | 拖动窗口标题区域调整位置，避免遮挡已选组件 |
| 展示空间 | 顶部“折叠组件库”“折叠配置区”可分别控制左右区域 |
| 移动预览 | PC 上设计，启用“移动端自适应”，进入预览后选择“手机 · 390”或“平板 · 768” |
| 已保存模型 | 顶部“模型 API”进入设置页；列表显示已保存服务、模型与默认状态 |
| 调用模型 | 打开“本地看板助手”，在“本次调用模型”选择已保存服务，再点击“使用所选模型生成医院概览” |
| 跨模型提示词 | “提示词样例”可复制业务提示词并粘贴模型的七字段 JSON 计划，校验后编译成原生 V3 |

手机指标卡按可用宽度排成两至三列，极窄区域允许单列。组件组合保留内部叠放；当前范围是 PC 设计与移动浏览，不包含手机开发看板。

## 门诊样例

具备本地数据后，在看板管理选择“门诊运营分析 · 五页样例”。它包含院级总览、ADS 科室分析，以及科室 → 医生 → 明细的局部样本链路。已有看板不会被样例自动覆盖。

1. 切换月份，查看指标、趋势、科室入口、口径与来源。
2. 点击配置的科室入口进入科室页，继续选择医生或下钻至明细。
3. 使用返回、面包屑、清除联动恢复分析上下文。
4. 表格“下载明细 CSV（已加载 N 行）”下载当前已加载范围；顶部 JSON 导出用于保存看板配置，两者用途不同。
5. 退出预览继续编辑，保存并重开验证配置。

联动、跳转、下钻、返回与下载由可见 Dashboard V3 配置和通用运行时实现。门诊七字段计划描述四页样本链路，编译器另附 ADS 科室页；当前不是任意业务看板生成器。

预算无来源时不生成预算组件。同比仅在去年同期可用且分母非零时计算，缺失或不可计算时提示。医生页面按现有局部样本展示，没有补造全量医生数据。
