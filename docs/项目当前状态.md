# 项目当前状态

当前业务版本为 V2.0，数据集、组件、图表、指标卡和数据计算底座已完成，正在进入 V3 Phase7 的模型与参数体系升级。Phase7 尚未开始业务编码。

更新时间：2026-07-23

## 当前版本

V2.0。`package.json` 的工程版本仍为 `0.1.0`，后续应单独统一产品版本与包版本。

## 已完成

- 数据集 2.0：目录、检索、分页、编辑、复制、状态、字段语义和查询参数定义。
- 组件体系：公共配置、图表、指标卡、表格专属配置及医疗业务模板。
- 图表能力：多维度、多指标、系列拆分、组合图、双轴、气泡图、标签和预警线。
- 指标卡：单位、格式、同比、环比、目标值和进度。
- 数据计算：分组、排序、SUM、AVG、MIN、MAX、COUNT、COUNT DISTINCT 和 NONE。
- 画布交互：八方向缩放、画布与标题自定义、本地保存、导入导出和预览。
- 数据链路：PostgreSQL/Greenplum 只读查询、服务端数据集执行和真实组件绑定。

## 当前进行

Phase7：V3 JSON、V1/V2 到 V3 的迁移与存储适配、参数中心基础能力。

本阶段以 [Phase7 实施方案](./02_V3架构/Phase7实施方案.md) 为最高优先级设计，详细交接见 [Phase7 开发交接](./02_V3架构/Phase7开发交接.md)。

## 未完成

- V3 JSON、JSON Schema、迁移报告、备份和失败回退。
- 参数中心，以及参数定义的模板、字典和校验。
- 参数运行时、筛选控件、数据集参数绑定和安全查询条件生成。
- 页面管理、统一事件、联动、下钻、导航和弹窗。

- 权限、查询缓存、AI 语义层和算法分析能力。

## 当前技术栈

前端：

- Vue 3.5、TypeScript 5.9、Vite 7。
- Vue Router、Tabler UI、Tabler Icons。
- ECharts 6。

后端：

- Node.js ESM 原生 HTTP 服务。
- `pg` 8.x 连接 PostgreSQL/Greenplum。
- 本机 JSON 保存数据源和数据集元数据。
- AES-256-GCM 加密数据库密码。

数据库：

- PostgreSQL/Greenplum。
- 固定验证库连接信息由本机私有配置提供；公开仓库只保留脱敏示例。
- Phase7 不新增数据库表。
